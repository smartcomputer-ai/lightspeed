Lightspeed v0.7.1 hardens the Platform image and improves Kubernetes non-root startup.

- Platform now uses Node 24.22.2 on Debian 13 Trixie and removes bundled npm/npx, Yarn, and unwanted development dependencies.
- Production dependency staging preserves locked package versions, required peers, and native optional dependencies.
- Platform, connector-host, and Configurator images declare numeric user/group IDs `1000:1000`, preserving their existing identity while allowing Kubernetes to verify `runAsNonRoot` from image metadata.

**Compatibility and upgrade**

This is a `restart-in-place` release from v0.7.0: `scripts/release/workflow-compat.sh v0.7.0` reports `restart-in-place`. Deploy matching v0.7.1 artifacts and restart the services; existing sessions can continue on their current Temporal namespace. Database schemas and public API, envd, and controller protocols are unchanged.

Platform moves from Debian 12 to Debian 13. Verify configured OIDC, custom CA trust, and PostgreSQL workload identity integrations after upgrading. Cluster policies that require explicit pod user/group fields still need those fields supplied.
