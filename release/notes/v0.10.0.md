Lightspeed v0.10.0 refreshes the Platform UI with a new visual design, expandable session and bot lists, clearer resource details, and a unified workspace file browser. A new Preferences page controls appearance and motion, and the demo gains interactive conversations.

Special thanks to **[Dan Krusi (@dankrusi)](https://github.com/dankrusi)**, who contributed most of the UI changes in this release.

**Compatibility and upgrade**

- This is a **restart-in-place release from v0.9.0**. `scripts/release/workflow-compat.sh v0.9.0` reports `restart-in-place`: the workflow implementation, its workspace dependencies and the Temporal SDK are unchanged. Keep the existing Temporal namespace; open work can continue after the restart.
- Runtime schema revision remains **24** and Platform schema revision remains **5**. There are no new database migrations or stored-format conversions in this release. Keep both databases and existing object storage.
- The API protocol identifier remains `lightspeed.agent.api.v1`, the envd protocol **5**, and the controller protocol **4**. The public API and SDK interfaces are unchanged. The Cargo lockfile changes only the five packages that carry the product version; external Rust dependencies stay locked.
- Existing browser preferences and drafts are preserved. Dark mode is the default where no theme has been chosen; a saved Light or System choice still applies. Preferences remain stored in the browser, without account synchronization.

**Moving from v0.9.0**

1. Back up the runtime and Platform databases, object storage and deployment secrets using your normal upgrade procedure.
2. Install matching v0.10.0 components from one release manifest. Keep the current databases and `TEMPORAL_NAMESPACE`.
3. Verify the runtime schema with `lightspeed-runtime schema-version`; it must remain **24**. Platform remains at schema revision **5**.
4. Restart the services and reload the browser to load the new UI. Check that existing sessions, bots and workspaces are available and open work continues.

Installations upgrading from before v0.9.0 must also follow the [v0.9.0 migration and namespace instructions](https://github.com/smartcomputer-ai/lightspeed/releases/tag/v0.9.0); this release does not replace those steps.

**A refreshed Platform**

- Updated dark and light themes, typography, surfaces and focus states, with a consistent duotone icon set, illustrated universe icons and a new Lightspeed logo.
- Starscape backgrounds in the sidebar and creation dialogs, with a subtle nebula behind page content. Creation dialogs prepare their background before opening.
- Consistent list and detail layouts, menus, tooltips, popovers, scrollbars and save feedback across resource pages. Browser tab titles identify the page and open resource.

**Sessions and bots**

- Session lists show the latest message beneath the title and use expandable trees for parent sessions and sub-agents. Bot lists nest conversations and their sub-agents under each bot, opening the relevant ancestors when a conversation is selected.
- Status and resource details are available from consistent toolbars and popovers: inspect activity, parent and sub-agent relationships, sharing, environments, workspaces and tools without leaving the current page.
- A bot's open conversation has its own header, separate from the bot's details.
- Right-click opens a row's actions. Session selection shows the available bulk close and delete actions with counts and confirmation.

**Workspaces**

- A unified file list shows folders and files with tree lines, file-type icons, keyboard navigation and row actions. Workspaces now sit directly below Sessions in the main menu.
- An open file's toolbar shows its saved type, size, line count for text, executable flag, content hash and workspace revision. Details let you copy the full hash or open the saved content in the blob viewer.

**Preferences and accessibility**

- The new Preferences page offers Light, Dark and System themes, a starscape toggle, and Reduced, Normal and System motion settings.
- Reduced motion follows the device setting by default and disables animations and moving backgrounds when enabled.
- Browser settings now use one shared store, preserving existing choices and keeping open tabs in step. Layout widths and unsent drafts remain local to the device.

**Demo**

- A welcome dialog explains the demo and can be dismissed permanently. It appears only in the demo.
- Two example sessions accept messages and produce simulated replies, with token usage reported for each run. Preferences includes a reset action to restore the demo data.
