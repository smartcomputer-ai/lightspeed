Lightspeed v0.11.0 is a **breaking release that requires migration**.

- Platform now manages organizations, universe access, and scoped credentials. The resource HTTP API supports CLI browser sign-in and service-user keys for automation.
- Universe creators become owners, universes support full deletion, and bots own their sessions. Organizations and access can be managed declaratively.
- Channels, the Telegram and WhatsApp connectors, and the legacy universe setup templates have been removed.

**Migration**

Use matching v0.11.0 components, fresh Runtime and Platform database baselines, and a new Temporal namespace. Operators can start fresh or migrate the data they need separately. This release provides no in-place conversion of existing databases or workflow histories. Review client integrations and access grants before switching traffic. [Upgrades and recovery](https://ls.bot/docs/deployment/upgrades-and-recovery/)
