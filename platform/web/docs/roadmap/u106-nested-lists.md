# U106: Nested Lists

Status: [todo]

Update the lists control, which is used, for example, on the bots listing, session listing, and profile listing, etc:

Nested rows should clearly be linked to the parent row. We do this by drawing a line from the parent that goes down to the child row and branches off with a small line ending in a small dot for the child row. The last row has a very nice curved radius for the branch off. There is a single line that drops from the parent and all the sub-children rows branch off From that single line. 

Nested rows beneath a parent don't have a separator line to symbolize that they belong to the parent. 

It should also be possible to have multiple levels of nesting.
