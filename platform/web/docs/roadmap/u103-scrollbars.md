# U103: Scrollbars

Status: [todo]

Create a unified scrollbar design system where the track is usually never visible. Only on hover does the track become visible and only the scrollbar itself is visible when hovering over the scroll area itself. Sort of like how Mac does it, use a narrower design as well and use official CSS styling only. 

This includes dialogues, text area scroll bars, etc. 

Also do an analysis and find areas where there is a double scroll bar. This needs to be solved. There should never be two scroll bars next to each other.

Scrollbar settings should be added to the surfaces in the design configurator as well.
